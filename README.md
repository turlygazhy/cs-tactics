# КС Тактики

Общая доска для тактик CS: радары карт, готовые тактики, рисование, которое видит вся команда.

Открыть: https://turlygazhy.github.io/cs-tactics/

- Аккаунты не нужны: любой, у кого есть ссылка, может рисовать.
- Синхронизация идёт через публичный MQTT-брокер (broker.emqx.io, запасные: HiveMQ, Mosquitto). Это тестовый вариант: брокер открытый, имя комнаты зашито в `sync.js`.
- Отдельная комната: добавь к ссылке `?room=любое-имя`.
